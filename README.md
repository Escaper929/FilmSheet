# FilmSheet

胶片扫描排版工具 —— 把你的数码扫描件变成真实的灯箱灯板 / 接触印相作品。

支持 135 和 120 两种画幅，物理级齿孔还原、结构化边字、自定义包装图、双语标签、**底片册**，一键生成专业级胶片展示图。

![Platform](https://img.shields.io/badge/platform-macOS%20%7C%20Windows-blue)
![Python](https://img.shields.io/badge/python-3.10+-blue)
![Version](https://img.shields.io/badge/version-v1.34-blue)

三个前端共用同一套渲染引擎：**桌面端**（Tkinter）、**移动网页版**（PWA，可安装到手机桌面）、**REST API**（FastAPI，可自建 / 部署到 NAS）。

## 功能特点

### 🎞️ 双画幅支持

| 画幅 | 子画幅 | 比例 |
|------|--------|------|
| **135** | 标准 36×24 | 3:2 |
| | 半格 18×24 | 3:4 |
| | 方形 24×24 | 1:1 |
| | XPan 65×24 | 65:24 |
| **120** | 6×4.5 | ≈1.35:1 |
| | 6×6 | 1:1 |
| | 6×7 | 1.25:1 |
| | 6×8 | ≈1.37:1 |
| | 6×9 | 1.5:1 |
| | 6×12 | 2:1 |
| | 6×17 | 3:1 |
| | 6×24 | 4:1 |

子画幅的合法值**取决于画幅**，桌面端切换画幅时选项自动更新；API 侧会做交叉校验，非法组合直接返回 400，而不是悄悄出一张比例错误的图。

### 🖼️ 真实还原

- **物理级齿孔** — KS（民用）和 BH（电影）两种齿孔样式，严格遵循 SMPTE 标准尺寸
- **自动齿孔类型识别** — 根据胶卷名称自动判断 KS / BH
- **4x 超采样抗锯齿** — 放大 4 倍绘制后 LANCZOS 缩小，边缘丝滑
- **结构化边字** — 上方显示品牌 + 胶卷型号，下方显示序号 + 三角形标记，模拟真实胶片边栏
- **中文品牌自动转英文** — 输入「柯达 Portra 400」自动转换为 `KODAK Portra 400`，电影卷自动识别为 `EASTMAN`
- **随机边字排列** — 上方边字位置随机分布，每次生成略有不同

### 📦 包装图叠加

- 支持导入胶卷包装图片（Kodak / Fujifilm 等）
- 左右位置可选，大小滑块调节
- 描边开关，自动适配
- 历史记录最近 30 张

### ✏️ 拍摄信息记录

- 卷号、相机、胶卷、拍摄日期、冲洗日期
- 冲洗方式、冲洗地点、扫描仪
- 中英双语标签一键切换
- 自动排版，超长文字自动缩放

### 🗂️ 底片册

渲染不再是一锤子买卖——每卷胶片都会自动归档，形成可检索的卷宗库。

- **自动归档** — 生成后自动入档；卷号 + 拍摄日期 + 胶卷派生唯一 ID，重渲不会产生重复记录
- **合并而非覆盖** — 二次渲染追加新的产物，不会丢掉上次生成的排版图
- **搜索与筛选** — 关键词实时搜索，可按胶卷 / 相机 / 年份筛选
- **多种排序** — 拍摄日期升降序、最近归档、卷号、张数
- **卷宗详情** — 右侧面板显示缩略图与全部拍摄信息
- **补录卷宗** — 手动录入没有排版图的卷宗
- **导入已有产物** — 扫描文件夹，从文件名解析卷宗信息并批量建档
- **归档位置可迁移** — 换盘 / 换目录时复制数据并改写配置，旧文件保留不动
- **文件丢失不丢档** — 产物文件不在了只标记「文件不在了」，卷宗记录保留

### 🎨 渲染风格

| 风格 | 描述 |
|------|------|
| **灯板正片** | 白色背景 + 暖色边字，模拟灯箱观看效果 |
| **接触印相** | 黑色背景 + 白色边字，经典接触印相风格 |

### ⚡ 高效批量

- **多线程并行处理** — 根据 CPU 核心数自动分配线程
- **正片 / 负片模式** — 一键反转色调
- **强制横向** — 竖图自动旋转 90°（6×4.5 反向处理）
- **自适应列数** — 根据画幅自动推荐最佳行列比
- **批量导出** — 同时生成灯板正片和接触印相两种风格
- **模板管理** — 保存和加载常用配置组合
- **水印签名** — 右下角添加个人签名水印

### 👁️ 预览功能

- 点击「预览」按钮快速查看渲染效果
- 用 80px 缩略图渲染，不等待完整生成
- 支持缩放和平移查看细节

### 🖌️ 界面

- macOS 风格视觉：自绘圆角控件、字体层级、深色标题栏
- **控件抗锯齿** — Tk Canvas 本身没有抗锯齿 API，界面用 PIL 超采样位图补上，Retina 下不再有锯齿
- 卡片圆角、悬停反馈、深浅色主题统一

## 快速开始

### 方式一：下载 Release（推荐）

1. 前往 [GitHub Releases](https://github.com/Escaper929/FilmSheet/releases) 页面
2. 下载对应平台的压缩包：
   - `FilmSheet-macOS-arm64.zip` — Apple Silicon
   - `FilmSheet-macOS-x86.zip` — Intel
   - `FilmSheet-Windows.zip` — Windows 单文件可执行程序
3. 解压后直接运行

> macOS 产物已去除 quarantine 属性，通常可直接双击打开。若仍被 Gatekeeper 拦截，在「系统设置 → 隐私与安全性」中点「仍要打开」。

### 方式二：从源码运行（桌面端）

```bash
git clone https://github.com/Escaper929/FilmSheet.git
cd FilmSheet
pip install -r requirements.txt
python main.py
```

### 方式三：API 服务 + 移动网页版

```bash
pip install -r api/requirements.txt
uvicorn api.main:app --port 8000
```

浏览器打开 `http://localhost:8000` 即是移动网页版（支持「添加到主屏幕」当 PWA 用）。接口文档在 `http://localhost:8000/docs`。

也可以用 Docker：

```bash
docker build -t filmsheet-api api/
docker run -d -p 8000:8000 filmsheet-api
```

或直接用仓库里的 `docker-compose.yml`。

## 使用说明（桌面端）

### 1. 准备图片

将胶片扫描件放入一个文件夹，支持 JPG、PNG、TIFF、BMP。建议扫描分辨率 300-600 DPI。

### 2. 基本设置

| 步骤 | 操作 |
|------|------|
| ① | 点击「浏览…」选择图片文件夹 |
| ② | 输入输出文件名（默认 `filmsheet_output.jpg`） |

### 3. 参数设置

- **成像模式** — 正片（原始色调）/ 负片（反转色调）
- **画幅** — 135 或 120，切换后子画幅选项自动更新
- **缩略图宽** — 数值越大越清晰，生成时间越长（**300–1200**，桌面端与 API 一致，默认 400）
- **每行列数** — 手动调整或点击「自适应画幅」自动设置
- **齿孔模式** — Auto（自动识别）/ KS（民用）/ BH（电影）
- **渲染风格** — 灯板正片 / 接触印相

### 4. 边字设置

- 留空则从「胶卷」字段自动生成：`品牌 型号`（上方） + `序号`（下方）
- 填写自定义内容则使用你输入的文本

### 5. 胶卷包装图（可选）

点击「浏览」选择包装盒照片，选择左 / 右位置，用滑块控制高度占比，可勾选描边。

### 6. 拍摄信息（可选）

填写拍摄与冲洗记录，支持中英文标签切换。未填写的字段会自动隐藏。

### 7. 水印签名（可选）

输入签名文字，显示在输出图片右下角。

### 8. 输出选项

- **格式** — PNG（无损）/ JPG（可调质量 1–100）
- **批量导出** — 勾选后同时生成灯板正片和接触印相两种风格

### 9. 模板管理

保存当前所有设置为模板，下次一键加载；也可删除不用的模板。

### 10. 预览与生成

点「预览」快速查看效果（缩略图速度），满意后点「开始生成」。完成后自动打开输出文件夹。

### 11. 底片册（第五个导航页）

生成结束后切到「底片册」页查看卷宗：搜索、筛选、排序、查看详情、补录、导入旧产物、迁移归档位置都在这一页。删除卷宗默认**只删记录不删文件**。

## 常见问题

**Q: 生成的图片模糊怎么办？**
A: 增大「缩略图宽」（建议 600–800px），数值越大最终图片越清晰。

**Q: 齿孔不对齐？**
A: 齿孔模式设为 Auto 时会根据胶卷名称自动判断 KS/BH；识别不准可手动指定。

**Q: 包装图显示不全？**
A: 选清晰、包装正面朝向的照片，宽高比别太极端。

**Q: 生成的文件名太长？**
A: 输出文件名会自动使用你填写的信息（卷号_相机_胶卷_日期），填得越简洁越短。

**Q: 底片册会重复记录吗？**
A: 不会。卷宗 ID 由卷号 + 拍摄日期 + 胶卷派生，同一卷重渲会合并进同一条记录。

**Q: 删归档会不会删掉我的图？**
A: 默认只删索引记录，产物文件保留。

**Q: 配置和归档数据存在哪？**
A: 都在系统标准目录，无需手动设置：

- macOS: `~/Library/Application Support/FilmSheet/`
- Windows: `%APPDATA%\FilmSheet\`
- Linux: `~/.config/FilmSheet/`

底片册的存放位置也可以在底片册页里改，或用环境变量 `FILMSHEET_ARCHIVE_DIR` 覆盖。

## 技术细节

- 渲染引擎基于 SMPTE 标准，齿孔尺寸精确到 0.001mm
- 135 模式 4 种子画幅各有不同的齿孔数与胶片前进距离；120 模式 8 种画幅自动计算裁剪比例
- 所有渲染 4x 超采样后 LANCZOS 降采样
- API 与桌面端**共用**同一批渲染器（`Renderer135` / `Renderer120`），不重复实现排版逻辑
- 中文品牌自动映射：柯达→KODAK、富士→FUJIFILM、伊尔福→ILFORD、乐凯→LUCKY 等
- 电影卷（Vision3、5207 等）自动识别为 EASTMAN 品牌
- 缩略图宽度上限 1200 是**资源约束**：渲染在 4x 超采样画布上进行，内存随宽度平方增长。实测 6 张 135、6 列下的峰值内存约为 400px→241MB、800px→887MB、1200px→2.9GB、1600px→5.4GB，故取 1200 为界
- 缩略图宽度范围只在 `config_schema` 定义一次，桌面端 Spinbox、API 参数校验、配置文件校验共用同一份常量
- 底片册数据采用原子写入（临时文件 + fsync + rename）；**逐条容错**——个别卷宗读不出来只跳过它自己并把原文件另存为 `.damaged-*`，其余卷宗照常显示（早先任何一条出错都会整库改名备份、当空库启动，看起来像数据全丢了）。整个文件连 JSON 都解析不了时才走 `.corrupt-*` 备份 + 空库启动

## 开发

```bash
# 桌面端依赖
pip install -r requirements.txt          # Pillow, ttkthemes

# 运行测试（macOS 若用 WorkBuddy 内置 Python 会缺 Pillow，请用系统 python3）
python -m unittest discover -s tests

# 分模块测试
python -m unittest tests.test_core       # 渲染管线
python -m unittest tests.test_archive    # 底片册
python -m unittest tests.test_config     # 配置容错
python -m unittest tests.test_ui_aa      # 抗锯齿质量与性能
python -m unittest tests.test_api        # REST API（需另装 httpx2）

# 底片册无头自测 / 渲染预览图
python tests/selftest_archive_ui.py
python tests/preview_archive_ui.py

# 打包
python setup.py py2app                       # macOS
pyinstaller main.spec --clean                # Windows / macOS 目录式包
```

CI 在每次 push 到 `main` 时跑测试；打 `v*` tag 时额外构建 macOS（arm64 + x86）、Windows 产物并创建 Release。
